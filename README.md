# NiTi Window Finder (web demo)

Presentation: https://amiryah1124.github.io/NiTi-Web-App/

Research prototype for exploring laser-power and scan-speed conditions within the original LPBF NiTi study domain

## Open
Open `index.html` through GitHub Pages, or download and open it locally in a browser. The app contains embedded data and has no backend or external JavaScript dependencies

## Scientific scope
- This is the archived **v1.5** prototype using the **GPR-based surrogate/UQ screening**
- Quantities labeled *joint screening frequency* are empirical results of residual scenario propagation
- The conditions shown are research-screening candidates, **not experimentally validated manufacturing recipes**. Experimental validation is ongoing
